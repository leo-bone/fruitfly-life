# 果蝇的一生 · 数字生命模拟 + 桌面宠物

两个原创项目，都基于真实果蝇神经回路结构，纯 Python 标准库，**你那台 Mac 直接能跑**。

## 项目一：果蝇的一生（叙事 / 内容素材）

`flylife.py` 是一个生命模拟引擎：一只果蝇从破蛹出生 → 青年觅食 → 壮年求偶 →
老年衰退 → 死亡，每一步由神经回路（ORN/AL/MB/GF/P1 等真实命名结构）驱动。
每只果蝇的一生都**唯一、可生成、可分享**。

```bash
python3 flylife.py            # 跑一只，打印它的一生故事
python3 report.py             # 批量模拟 20 只，挑最有故事的一只，生成 life_XXXX.html
```

`life_XXXX.html` 是可分享的可视化：生命能量/体魄曲线、神经活动曲线（GF 巨纤维、
MBON 效价、PAM 多巴胺、M_court 求偶）、人生时间轴，右下角还有一只会飞的果蝇。

**内容钩子**：「我让一群果蝇在电脑里活了一生，最传奇的一只躲过 10 次捕食、
求偶 6 次、留下 65 枚卵，最后寿终正寝」「这只运气差的，第 11 天就被蜘蛛拍中」。
批量生成 → 挑极端样本 → 连载，天然适合 B站/抖音/公众号。

## 项目二：桌面宠物（常驻桌面）

`desktop_pet.py` 用 tkinter 做一个常驻桌面右上角的小窗，一只果蝇会"飞"，
实时演化它的一生（约每 2.5 秒一天）。点击拖动，右键「重生一只」。

```bash
python3 desktop_pet.py
```

> 参考原型：这波热潮里的 DesktopFly（GitHub 835 星）用 FlyWire 668 个神经元的
> 逃跑/转向/梳理电路跑 1kHz 脉冲仿真，让一只 3D 果蝇住在 macOS 桌面上。
> 本版用更轻的 rate-based 回路 + tkinter，好处是零依赖、跨平台、你随时能改。

## 诚实声明（写内容时必须带上）
- 连接组是**接线图，不是大脑**；本程序用真实回路的**命名与连接方向**，
  但权重是示意性的，并非 MaleCNS 实测权重。
- 它不声称复现某只真实果蝇的意识，而是「用真实回路结构驱动一段被设计的人生」。
- 学术对照：打乱连接权重的网络往往表现相似 → 所以定位是**模拟/科普/叙事**，
  不是「数字生命突破」。这个分寸本身就是最好的内容差异化（别人吹，你拆穿）。

## 怎么升级成「真·连接组」版本（进阶）
1. 下载真实权重表（1.1 GB，CC BY 4.0）：
   `bash ../stonkfly-cn/fetch_data.sh ./male-cns-data`
2. 用 `pyarrow` 读 `connectome-weights-*.feather`，取你关心的**真实子图**：
   - 逃逸：GF（巨纤维）→ TERG → 运动神经元
   - 求偶：aCC → P1 → JCX → 运动
   - 嗅觉：ORN → AL → MB(KC) → MBON
3. 把 `flylife.py` 里 `W`（示意权重）替换为该子图的真实边权重，其余世界模型不变。
   注意：完整 16 万神经元在你的 Mac 上跑不动，必须取子图（几百~几千节点足够讲故事）。

## 文件清单
- `flylife.py`      —— 生命模拟引擎（示意权重版，零依赖，立刻能跑）

- `life_*.html`     —— 生成的可视化报告（示例）

# 三、升级成「真·连接组」果蝇一生（用户要的"用 1.1GB 真实权重、简化"）

> ✅ 沙箱已验证：`build_circuit.py` 已改为**纯 pyarrow（无 pandas 依赖）**；
> 注释表真实列名 `bodyId`/`type` 命中（21 万神经元）；回路关键词修正后精确匹配到
> 真实节点——escape 7 个 type（GFC2/3/4、TTMn…）、courtship 38 个（mAL*、pIP10…）、
> olfactory 562 个（MBON01、OA-AL*…），共约 5396 节点，你的 Mac 轻松跑得动。
> 权重表（1.1GB）正在后台下载，完成后会自动跑出真实 circuit.json + 真实版报告。

1. 装依赖 + 下数据（在你自己 Mac 上，比沙箱快得多）：
   ```bash
   pip install pyarrow
   bash ../stonkfly-cn/fetch_data.sh ./male-cns-data
   ```
2. 抽真实子图（只保留真实功能回路，规模可控、Mac 跑得动）：
   ```bash
   python3 build_circuit.py --out circuit.json --max_per_type 60
   ```
   这会从 1.1GB 边表里，按真实果蝇回路关键词（GF 逃逸 / aCC→P1→JCX 求偶 /
   ORN→AL→MB 嗅觉）挑节点，输出很小一份 circuit.json。
3. 跑真实连接组版的一生 + 出酷报告：
   ```bash
   python3 flylife_real.py circuit.json      # 单只
   python3 report.py --real                  # 批量挑最有故事的一只 → life_real_XXXX.html
   ```

**诚实边界不变**：权重是真边权重，但连接组仍只是接线图（不含可塑性/神经肽/实时活动），
所以这是"用真实神经结构驱动一段被设计的人生"，定位模拟/科普/叙事。
