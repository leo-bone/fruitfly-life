诚实边界（务必先读）

真实的部分：连边权重是 MaleCNS v1.0 连接组的真实突触权重；节点和接线是真实果蝇脑里的真实神经元类型与真实接线。
模拟的部分：连接组只是一张「接线图」，不是会思考的大脑。果蝇「一生」的行为与死亡是示意性 rate-based 模型（能量/健康/GF/MBON/PAM/求偶信号随时间变化），不是对真实神经放电的复现；网络图的力导向布局仅为可读性，不代表真实空间位置。
定位：这是模拟 / 科普 / 叙事作品——用真实的脑接线结构去讲一只果蝇「可能的一生」，不声称复现意识或真实行为。
页面内可查：模拟器右上角有 ⓘ 诚实边界 按钮，随时可复核哪些数字来自真实连接组（5,396 节点 / 289,144 条真实突触连接 / 607 种神经元类型），哪些是示意模型。

怎么分享 / 托管

本主页与子页面都是零外部依赖的自包含 HTML，任意一种方式即可分享：
① 把 flylife.html（或连同 index.html / collection.html / connectome.html）打包发给别人，双击即可打开；
② 本地起服务预览：在 flylife 目录运行 python3 -m http.server 8000，浏览器访问 http://localhost:8000；
③ 丢到任意静态托管（GitHub Pages / Vercel / 对象存储 / 你的服务器）即可拥有在线链接。
分享「某一瞬间」：模拟器里点「暂停思考」会把它把当前种子与天数写进网址（如 flylife.html#seed=4828&day=12.3），把这个链接发给别人，对方一打开就停在你分享的那一刻。
保存反思卡片：「暂停思考 / 它的一生结束了」弹窗里点「📥 保存卡片」可下载一张 1080×1350 的竖版图片，「📋 复制文字」可复制金句，方便发朋友圈 / 群。
